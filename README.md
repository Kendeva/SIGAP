# SIGAP — Smart Food Freshness Check

SIGAP is a local Streamlit application with **photo screening as the primary feature** and legacy inventory analysis as a supporting tool. It does not require an OpenAI API key, a paid inference API, or a hosted inference service.

## Three pages

1. **Photo Check** — upload a fruit photo and screen for visible Fresh/Rotten signs using a locally trained MobileNetV3-Small model.
2. **Inventory Analysis** — use the existing Decision Tree model to assess leftover-stock risk for one product. Multi-product CSV analysis remains optional.
3. **Models & Data** — inspect model status, inventory evaluation metrics, the sample dataset, and the Decision Tree visualization.

## Two models, two purposes

- `models/sigap_mobilenetv3_best.pt`: the fruit-image model. It is generated by the training pipeline and is not included in this ZIP; train it on your machine or copy in your existing checkpoint.
- `models/food_waste_model.joblib`: the legacy Decision Tree model for inventory leftover-risk analysis. This file is included.
- `data/data_penjualan.csv`: the legacy sales dataset with 80 rows. It is included as a sample for Inventory Analysis.

The photo model classifies visual patterns in fruit types represented in its training data. The inventory model classifies stock records, not the visual condition of fruit. Their outputs are not interchangeable.

## Run on Windows

Python 3.11 or 3.12 is recommended.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-train.txt
streamlit run app.py
```

The application will run at the local address printed in the terminal, usually `http://localhost:8501`.

### If you have already trained the photo model

Before copying this project into a new folder, copy the photo checkpoint and metrics from your existing SIGAP project if available:

```text
models/sigap_mobilenetv3_best.pt
models/metrics.json             (optional)
models/training_history.csv     (optional)
```

Place these files in the new project's `models/` folder to avoid training again. This ZIP includes the legacy inventory model and CSV, but it cannot automatically include a photo checkpoint stored only on your computer.

### If the photo model is not available

Download the image dataset and train the model:

```powershell
python scripts/download_dataset.py
python scripts/train_model.py
```

Images are exported to `data/raw/Fresh` and `data/raw/Rotten`. The raw image dataset is not included in the ZIP because of its size. Training creates `models/sigap_mobilenetv3_best.pt`.

Dataset source: [Project-AgML/fresh_rotten_fruit_classification](https://huggingface.co/datasets/Project-AgML/fresh_rotten_fruit_classification), licensed under CC BY 4.0. Review the dataset card and retain attribution when sharing derivative work.

## Inventory analysis and optional CSV

The legacy `data/data_penjualan.csv` includes `stok`, `terjual`, `hari_ke`, `cuaca`, `hari_besar`, `sisa_persen`, and `label`. The user-facing CSV template uses English column names and accepts the following fields:

```csv
product_name,stock,sold,day_index,weather_code,special_day
Apple,100,65,15,0,0
Banana,80,30,8,1,0
```

`product_name` is optional. The application derives remaining stock from `stock` and `sold`. The `weather_code` field uses 0/1, but the meaning of these codes is not documented in the legacy dataset source. Existing CSV files with Indonesian column names are still supported for backward compatibility.

The inventory model uses only 80 rows, and its labels are strongly associated with the remaining-stock percentage. High evaluation scores on this small dataset **do not prove real-world accuracy**. Treat it as a learning prototype, not as the sole basis for inventory decisions.

## Dependencies and training

- `requirements.txt`: application dependencies.
- `requirements-train.txt`: application dependencies plus the image dataset downloader and training dependencies.
- `src/local_vision.py` and `src/model.py`: local image inference and image-model architecture.
- `scripts/download_dataset.py` and `scripts/train_model.py`: image-model training pipeline.
- `src/predictor.py` and `src/train_model.py`: legacy inventory prediction and retraining pipeline.
- `tests/`: tests for both model workflows.

To retrain the inventory model from the included CSV:

```powershell
python src/train_model.py
```

Run all tests with:

```powershell
python -m pip install pytest
python -m pytest -q
```

## Limitations

- The photo model classifies images based on its training classes; it does not cover every food type.
- The photo score is not a calibrated food-safety probability. A Fresh prediction does not guarantee that food is safe to eat.
- The legacy inventory model and dataset are small examples. They do not predict expiry dates or future demand.
- Do not upload raw image datasets, virtual environments, or secrets to GitHub. The small inventory model and example CSV are included; the trained photo checkpoint can be excluded depending on file size and licensing considerations.
